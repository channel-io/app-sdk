# 設定画面に連携情報を表示

## どのような機能ですか

アプリや外部サービスから取得した情報を、チャネルトークの標準設定画面に表示する機能です。
ユーザーは設定画面で、連携した店舗の名前やドメインなど、アプリが提供する情報を確認できます。

`config.display.load` フックに情報を取得するアプリ関数を指定すると、設定画面が関数を呼び出し、
返された値を読み取り専用フィールドに表示します。画面のコードを別途書くことなく、既存の
Config フィールドを使用できます。

表示した値は Config に保存しません。元のデータはアプリや外部サービスで管理し、
設定画面には取得した結果を表示します。

## どのようなときに使いますか

アプリが持っている情報をユーザーに入力してもらうことなく、設定画面で確認できるようにしたい
ときに使います。

- **連携先を確認するとき**: 店舗名とドメインを表示し、どの店舗と連携しているかを伝えます。
- **外部サービスで管理している情報を表示するとき**: 利用中のプランや契約の有効期限を取得して表示します。
- **アプリの処理状況を表示するとき**: 最終同期日時や処理した注文数を取得して表示します。

設定画面を開いたときや、設定の保存・連携の完了後に画面を更新するときに、値を再取得します。
画面を開いている間に定期的に更新したり、ユーザーが入力値を変えるたびに取得したりする機能では
ありません。

ユーザーが入力した値を保存し、その後のアプリ関数で使う場合は、通常の Config フィールドを
使用してください。

## 例: 連携した店舗の情報を表示

EC 連携アプリで店舗名とドメインを表示する例です。ユーザーはアプリの設定を開いて、
連携した店舗が正しいか確認できます。

| 項目     | 表示する値       |
| -------- | ---------------- |
| 店舗名   | チャネルショップ |
| ドメイン | shop.example.com |

実装に必要なのは、値を表示するフィールドと、店舗情報を取得するアプリ関数です。

### 1. 表示するフィールドと取得用の関数を設定

`metadata.getConfigSchema` のレスポンスに店舗名とドメインのフィールドを定義し、`hooks` に
呼び出す関数名を指定してください。

```json
{
  "schemaVersion": "v1",
  "configScope": "channel",
  "providerName": "Shop",
  "hooks": [
    {
      "type": "config.display.load",
      "actionFunctionName": "shop.getDisplayValues"
    }
  ],
  "blocks": [
    {
      "type": "text",
      "key": "storeName",
      "label": "店舗名",
      "readOnly": true,
      "storageClass": "transient",
      "overviewSummary": true
    },
    {
      "type": "text",
      "key": "storeDomain",
      "label": "ドメイン",
      "readOnly": true,
      "storageClass": "transient",
      "overviewSummary": true
    }
  ]
}
```

各フィールドに `readOnly: true` と `storageClass: "transient"` を両方指定します。
ユーザーによる編集を防ぎ、値を保存対象から除外する設定です。

この例では単一設定を使います。`overviewSummary: true` を追加すると、保存済みの連携の
概要画面にも情報を表示できます。

### 2. アプリ関数から店舗情報を返す

`shop.getDisplayValues` を通常のアプリ関数として登録し、対象チャネルに連携した店舗情報を
取得する処理を実装してください。関数名はアプリで決められますが、`actionFunctionName` と
一致させる必要があります。

この例では、関数の入力値は `{}` です。対象チャネルは、認証済みの呼び出し情報にある
`ctx.channel.id` で確認します。データの取得とアクセス権限の確認は、アプリ関数で行います。

取得した値は、次の形式で返します。

```json
{
  "displayValues": {
    "storeName": "チャネルショップ",
    "storeDomain": "shop.example.com"
  }
}
```

`displayValues` のキーは、先ほど定義したフィールドの `key` と一致させます。このレスポンスを
受け取ると、設定画面の「店舗名」に「チャネルショップ」、「ドメイン」に「shop.example.com」を
表示します。

関数の役割は、表示する情報の取得だけです。設定の保存や外部データの変更は含めません。

### 3. 情報がない場合や取得に失敗した場合の処理

店舗をまだ連携していないなど、表示する情報がない場合は、次のように返すことができます。

```json
{
  "displayValues": {}
}
```

空のオブジェクトを返すと、同じ対象の以前の表示値のうち、現在のフィールド定義で有効な値を
維持します。以前の値を消すには、対象のキーに `null` を返してください。

```json
{
  "displayValues": {
    "storeName": null,
    "storeDomain": null
  }
}
```

取得に失敗すると、設定画面にエラーと再試行ボタンを表示します。同じ対象で最後に取得に成功した
値があれば、その値を維持します。

表示値は保存リクエストや、その後の関数呼び出しの `ctx.config` に含まれません。連携の完了は
別途検証するため、情報が表示されたことだけで連携の成功を判断しないでください。

---

この機能を使うには、`config.display.load` に対応した AppStore サーバーと標準設定画面が必要です。
SDK 0.24.2 の `GetConfigSchemaOutputSchema` を使用している場合は、`hooks` 配列と `readOnly`
プロパティを保持するため、`metadata.getConfigSchema` の出力スキーマを
`@OutputSchema(z.record(z.string(), z.unknown()))` に指定してください。
